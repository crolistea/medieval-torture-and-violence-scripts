# Catalogue images

One image per script, shown on the home page.

Name the file after the module's slug (the `slug` in `src/data/modules/`):

- `medieval-torture-devices.jpeg`
- `violence-and-shit.png`
- `very-very-extreme-violence.jpeg`

`.jpg`, `.jpeg`, `.png`, `.webp` and `.avif` all work. Images are cropped to
3:2, so 1500 x 1000 is a good size. A script with no file shows an empty slot.

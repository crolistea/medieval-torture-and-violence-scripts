# Contributing

Contributions are welcome.

## Before changing code

- Search existing issues and pull requests first.
- For substantial changes, open an issue describing the problem and proposed direction.
- Keep changes focused. Avoid unrelated formatting or generated-file churn.

## Development

The repository contains the JanitorAI JavaScript modules, a Vite/React installation site, and developer tooling under `tools/`.

For the Prompt Inspector, `nix develop` provides the Go, Node, Python, and Rust toolchain when Nix is available.

## Pull requests

Describe what changed and why. Link relevant issues with syntax such as `Closes #123` when the pull request fully resolves them. Test the component you changed before requesting review.

## Safety and historical material

Keep historical claims appropriately qualified and distinguish documented devices from disputed, reconstructed, or misattributed material. Fiction-oriented action modules should remain cinematic rather than instructional.

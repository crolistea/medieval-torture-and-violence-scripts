# Accessibility

The project aims for the GitHub Pages installation site to remain usable with keyboard navigation, readable contrast, semantic HTML, and responsive layouts.

## Supported environment

The site targets current standards-based desktop and mobile browsers. The command-line Prompt Inspector is primarily terminal-based.

## Known limitations

Accessibility testing is currently manual rather than backed by a complete automated audit suite. Some developer-tool output is optimized for terminal use.

## Reporting barriers

If you encounter an accessibility barrier, open a GitHub issue describing the page or component, device/browser or assistive technology when relevant, and what prevented you from completing the task. Please do not include sensitive personal information.
